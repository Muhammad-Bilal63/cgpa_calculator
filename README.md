# 🎓 CGPA Calculator

A simple and user-friendly **CGPA Calculator** developed to calculate a student's cumulative grade point average based on course grades and credit hours.

## 📌 About the Project

This project was created as a programming task to provide an easy way for students to calculate their CGPA.

The calculator takes the **course grade** and **credit hours** into account and calculates the overall CGPA.

## ✨ Features

- 🎓 Calculate CGPA easily
- 📚 Supports multiple courses
- ⏱️ Quick and simple calculations
- 🖥️ Runs on Windows
- 🧮 Calculates CGPA based on credit hours
- 👨‍🎓 Designed for students

## 🛠️ Technologies Used

- **C++**
- **Standard Input/Output**
- **Windows Executable (.exe)**
